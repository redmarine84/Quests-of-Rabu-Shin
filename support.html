Discord Support Server

Open RabuShin Support Server

The support server must be configured in site-config.js before public release and added to Discord Developer Portal Discovery Settings.

Before reporting a problem

  • Restart the Activity and confirm Discord authentication succeeds.
  • Confirm your own OpenAI API key is saved in Settings if the problem involves the AI Game Master.
  • Do not post OpenAI API keys, Discord OAuth tokens, Supabase keys, passwords, or other secrets in support messages.
  • Include the error text, what screen you were on, and what you were trying to do.

Billing / OpenAI usage

RabuShin does not manage OpenAI billing. Each player is responsible for their own OpenAI account, credits, usage, and API-key lifecycle.

Privacy or deletion requests

Use the Data Deletion page for requests involving stored RabuShin data.
